# 🛡 Enterprise Windows Monitoring with Wazuh SIEM

> Enterprise-grade Windows 11 monitoring using Wazuh SIEM, Sysmon and custom detection engineering.

---

## 📖 Overview

This project demonstrates the implementation of a Security Information and Event Management (SIEM) platform focused on monitoring Windows 11 endpoints.

The environment simulates a real Security Operations Center (SOC), combining Windows Event Logs, Sysmon telemetry and custom Wazuh detection rules to identify malicious activities while reducing unnecessary operating system noise.

The primary monitoring scenarios include:

- 🔌 USB Device Monitoring
- 🖥 Remote Desktop Protocol (RDP)
- 🌐 External Network Connections
- ⚙ Process Monitoring
- 🚨 Threat Detection
- 📊 Custom Security Dashboards
- 🛡 MITRE ATT&CK Mapping

Rather than simply deploying Wazuh, this project focuses on building a realistic detection engineering lab following enterprise security monitoring best practices.

---

## 🎯 Project Objectives

The main objective of this project is to build a realistic Windows Security Monitoring environment capable of detecting malicious activities through custom detection rules and effective event correlation.

The project also aims to develop practical skills in:

- Security Information and Event Management (SIEM)
- Detection Engineering
- Windows Security Monitoring
- Windows Event Logs
- Sysmon Configuration
- Threat Hunting
- MITRE ATT&CK Framework
- Dashboard Development
- Noise Reduction
- Incident Investigation
