
# 📖 Project Overview

## Introduction

This project demonstrates the implementation of an enterprise-style Security Information and Event Management (SIEM) laboratory using **Wazuh** to monitor a **Windows 11** endpoint.

The lab was designed to simulate a real Security Operations Center (SOC) environment, focusing on endpoint visibility, threat detection, event correlation, and security monitoring.

The entire environment runs on **VirtualBox** and consists of three virtual machines:

- Ubuntu Server 24.04 (Wazuh Server)
- Windows 11 Pro (Monitored Endpoint)
- Kali Linux (Attack Workstation)

---

# Project Objectives

The main objective of this project is to build a realistic SIEM environment capable of detecting and monitoring security events generated by a Windows endpoint.

The lab focuses on:

- Endpoint monitoring
- Security event collection
- Detection engineering
- Custom Wazuh rules
- MITRE ATT&CK mapping
- Dashboard creation
- Alert validation
- Noise reduction

---

# Architecture

The infrastructure follows a centralized monitoring architecture.

```
Windows 11
     │
     ▼
Sysmon
     │
     ▼
Windows Event Logs
     │
     ▼
Wazuh Agent
     │
     ▼
Ubuntu Server
     │
 ├── Wazuh Manager
 ├── Wazuh Indexer
 ├── Wazuh Dashboard
 └── Filebeat
```

Kali Linux is used exclusively to generate attack scenarios for validation purposes.
